flow

Server-autoritatives Zuhause für Worktime, Wissen und Agenten-Kontext — für Menschen und KI-Agenten.

flow ersetzt eine Handvoll getrennter Werkzeuge — Zeiterfassung, Notiz- und Wissens-Kompendium, Projekt-Metadaten, Agenten-Gedächtnis — durch einen autoritativen Server, den man von überall erreicht: per CLI, TUI, Browser und über MCP direkt aus einem KI-Agenten heraus.

Die drei Binaries

  • flow-server — der API- und SSE-Server und die Komposition. Postgres-gestützt, OIDC-geschützt, live über Server-Sent-Events. Alle Autorität lebt hier.
  • flow — der Client: eine Cobra-CLI (worktime, node, docs, context, login, …) und, ohne Subkommando, eine Bubble-Tea-TUI.
  • flow-mcp — ein MCP-Server, der flow als geräteübergreifenden Wissens- und Kontextspeicher für KI-Agenten öffnet.

PackageInfo synchron injizieren

Fix für die Produktionsstörung „Deine App-Version ist zu alt" beim Spiel-Erstellen und -Beitreten mit App 0.46.3. Von Soenne freigegeben (Option A, 05.08.2026). Root Cause ist bestätigt — nicht erneut diagnostizieren.

MSMartin Söntgenrath schrieb vor 6 Tagen · strassenfuchs / plans / 2026-08-05-package-info-sync-injection · 3 min BearbeitenAnpinnen

Root Cause — bestätigt 05.08.2026

Der Bug ist ein Riverpod-Lifecycle-Problem, KEIN Android-Problem. Die frühere Diagnose „packageInfoProvider erreicht auf Android nie den data-Zustand" war ein Fehlschluss — die Versionszeile auf dem Handy wurde vermutlich übersehen, 10 px bei 30 % Alpha.

Ablauf:

  1. Tap auf „NEW GAME (Host)" → lobby_screen.dart _createSessionAndJoin() setzt _isLoading = true → der Body ersetzt JoinCreateView durch den Spinner.
  2. Die Versionszeile ist der einzige ref.watch-Listener des packageInfoProvider — der ist autoDispose. Unmount → Provider disposed.
  3. _clientVersion() = ref.read(packageInfoProvider).value?.version → erzeugt einen frischen Provider im AsyncLoading-Zustand → .value == null.

Fix — Option A, freigegeben

PackageInfo beim App-Start auflösen und synchron injizieren, exakt nach dem existierenden localStorageProvider-Muster.

lib/src/shared/providers.dart · dart
@Riverpod(keepAlive: true)
PackageInfo packageInfo(Ref ref) {
  throw UnimplementedError('packageInfo must be overridden in main()');
}
