Architektur

Die WebUI ist server-gerendert mit templ-Komponenten und htmx für partielle Updates — kein SPA-Framework, eine Binary, ein Deploy.

  • · Komponenten in templ, getypt zur Compile-Zeit
  • · Interaktion via htmx-Attribute, kein Client-State
  • · Live-Sync über SSE — der Timer tickt serverseitig

Die Tokens leben zentral in [[Design-Tokens]] — siehe Tag #tokyonight.

Schicht Tech
Web templ + htmx
Stil Tailwind

Stylesheet bauen mit make web:

$ tailwindcss --input web/tailwind.css \
  --output static/app.css --minify
